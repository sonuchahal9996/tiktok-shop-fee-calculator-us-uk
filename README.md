# 2026/2027 TikTok Shop US & UK Fee & Profit Calculator (TokFeeCalc)

Open-source calculation engine for TikTok Shop seller referral fees (6% US / 9% UK), creator affiliate commissions, FBT vs merchant shipping, and net profit margins.

### 🚀 Production Live Web Application
Official Web Tool: [https://tokfeecalc.com/](https://tokfeecalc.com/)

### Features
- US (6% Unified Policy) & UK (9% Standard Policy) live rate calculation
- Target Margin reverse pricing finder
- Complete cost breakdown (COGS, shipping, ad spend, affiliate payout)
